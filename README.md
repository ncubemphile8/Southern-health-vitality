# Southern Health & Vitality Physiotherapy

A responsive public website and interactive practice-management presentation demo for Southern Health and Vitality Physiotherapy, Bulawayo, Zimbabwe.

## Included
- Cinematic hero, wellness imagery, responsive layout, scroll animations and reduced-motion support.
- Public service pages, practitioner introduction, contact/location details and appointment-request demo form.
- Interactive staff dashboard: overview, fictional patient directory, patient monitoring, appointments, payments, follow-ups and reports.
- Add/edit sample patients, add progress measures and clinical notes, create appointments, record sample payments, print demo summaries/receipts, export CSV reports, and reset sample data.
- Browser-local demo storage only.

## Run / deploy
This is a static site. Open `index.html` locally or connect this repository to Vercel. Use the repository root as the project root, no build command, and no output directory override.

## Important safety note
**This is a presentation prototype, not a production clinical records system.** Every patient and transaction is fictional. Demo changes are saved in the current browser only. Do not enter real patient information. The staff dashboard is intentionally accessible for the presentation; before real use, add server-side authentication, role-based authorisation, a secure database, encrypted transport and storage, audit logs, backups, consent and retention workflows, and a privacy/legal review. Appointment requests are not transmitted to the clinic, and no automated messages are sent. The public form explicitly indicates this.
