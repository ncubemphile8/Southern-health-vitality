# Southern Health and Vitality Physiotherapy

Premium public website and practice management demo for Southern Health and Vitality Physiotherapy, Bulawayo, Zimbabwe.

All patient records and transactions in this demo are fictional. Do not enter real patient information. The static demo uses browser storage and is not a secure clinical records system.

## Run locally
Open `index.html` in a browser, or serve the repository as a static site. Deploy to Vercel as a static project with no build command and the repository root as the output directory.
